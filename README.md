## Getting started

```bash
git clone https://github.com/nisrulz/flutter-examples.git
cd flutter-examples
make packages
cd <example-folder>
flutter run
```

New to Flutter? See [Getting Started](/documentation/GETTING_STARTED.md) for full setup and run instructions.
